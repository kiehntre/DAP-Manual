# DAP Retro Bible Style Guide

This document defines the editorial standards for the DAP Retro Bible.

## Principles

- Write in UK English.
- Be accurate before being clever.
- Prefer tested instructions.
- Linux-first.
- One subject per chapter.
- Keep historical notes factual.

## Markdown

- One H1 per file.
- Use H2/H3 consistently.
- Fenced code blocks with language.
- Tables for comparisons.

## DAP Tips

Use a blockquote beginning with **DAP Tip:**.

## Hall of Fame / Hall of Shame

Keep entries factual, concise and evidence-based.

## Images

Use lowercase kebab-case filenames and include alt text.

## Citations

Prefer official documentation and primary sources where possible.

## Chapter Template

1. Introduction
2. Historical context
3. Concepts
4. Practical tutorial
5. Troubleshooting
6. Summary
