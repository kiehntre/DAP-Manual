# DAP Retro Bible

The DAP Retro Bible is the practical retro gaming and preservation guide for the DAP homelab.

It is written for a Linux-first setup, with Sunshine/Moonlight streaming, ES-DE, LaunchBox where useful, RomM, emulators, BIOS organisation, texture packs, patches, metadata, and sane storage layouts.

## Structure

- `chapters/` - main guide chapters.
- `appendices/` - reference material, command notes, emulator tables, BIOS checklists, and preservation notes.
- `assets/` - screenshots, diagrams, and supporting images.

The second EmuWiz mega-pass is an operational companion to the preservation
chapters. It extracts lessons from real scanning, launch, cheat, packaging,
recovery and QA work without turning the Bible into a commit log. Each chapter
labels current behavior as implemented, partial, researched or future-facing.

## Writing rules

- Prefer tested commands over theory.
- Keep Linux paths explicit.
- Separate legal ownership, preservation, and emulator configuration clearly.
- Record real-world fixes, not polished fairy dust.
