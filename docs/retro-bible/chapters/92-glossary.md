# Glossary

The glossary is where the book's language becomes easy to revisit.

This chapter is a skeleton reference for terms that appear throughout The DAP Retro Bible. Later passes should expand definitions, add cross-links and keep wording consistent with the style guide.

## Core Terms

| Term | Meaning |
| --- | --- |
| ROM image | A dumped copy of cartridge or memory data. |
| Disc image | A dumped copy of optical media. |
| BIOS | Low-level firmware needed by some emulators. |
| Firmware | System software broader than BIOS. |
| Emulator | Software that recreates another system. |
| Core | A libretro emulator module. |
| Frontend | A launcher and library interface. |
| Metadata | Artwork, titles, descriptions and related library data. |
| DAT | A verification database file. |
| Checksum | A fingerprint for file identity. |
