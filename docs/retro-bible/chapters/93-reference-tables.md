# Reference Tables

Reference tables are not a substitute for chapters. They are the quick map you use after reading the chapters.

This chapter is the skeleton for tables that later passes should fill with checked, cited and version-aware information.

## Emulator Reference

| System | Primary emulator | Notes |
| --- | --- | --- |
| GameCube/Wii | Dolphin | RVZ workflow. |
| PS2 | PCSX2 | BIOS required. |
| PS3 | RPCS3 | Firmware required. |
| PSP | PPSSPP | Strong Linux support. |
| Arcade | MAME | Set version matters. |

## Format Reference

| System type | Common format | Notes |
| --- | --- | --- |
| CD systems | CHD or BIN/CUE | Check emulator support. |
| GameCube/Wii | RVZ | Dolphin-friendly. |
| Wii U | WUA | Cemu-friendly. |
| Arcade | ZIP and CHD | Do not extract blindly. |
