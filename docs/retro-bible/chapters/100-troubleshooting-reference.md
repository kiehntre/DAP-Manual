# Troubleshooting Reference

Troubleshooting is easier when symptoms have a first place to go.

This chapter is the skeleton for a practical triage reference that points back to deeper chapters.

## Game Does Not Launch

Check:

- emulator path;
- file format;
- BIOS or firmware;
- permissions;
- frontend launch command;
- logs.

## Game Launches but Controls Fail

Check:

- emulator input profile;
- Steam Input;
- controller order;
- streaming virtual controller;
- per-game special controls.

## Save Is Missing

Check:

- emulator install method;
- Flatpak versus native paths;
- old memory card files;
- changed game filename or region;
- backup history.

## Stream Stutters

Check:

- host performance;
- network quality;
- bitrate;
- encoder;
- client decode;
- TV game mode.

## Metadata Is Wrong

Check:

- filename;
- scraper match;
- region;
- hack or translation status;
- frontend cache.

> **DAP Tip**
>
> Change one thing at a time while troubleshooting. Retro stacks have enough layers without adding your own fog.
