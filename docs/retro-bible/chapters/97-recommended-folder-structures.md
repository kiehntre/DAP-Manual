# Recommended Folder Structures

Folder structure is not glamorous. It is just the thing that decides whether the library still makes sense in five years.

This chapter is the skeleton for the book's recommended layouts.

## Base Layout

```text
/mnt/games/
  bios/
  roms/
  saves/
  states/
  patches/
  texture-packs/
  metadata/
  backups/
  maintenance/
```

## Source and Working Copies

```text
/mnt/games/verified/
/mnt/games/roms/
/mnt/games/conversions/
```

## PC Games

```text
/mnt/games/pc/msdos/
/mnt/games/pc/windows/
/mnt/games/pc/patches/
/mnt/games/pc/manuals/
```

## Practical Advice

- Use lowercase system folders.
- Keep source material separate from generated copies.
- Keep saves and states backed up.
- Do not let frontend folders become the only source.

> **DAP Tip**
>
> A good folder layout is boring enough that another person can guess where something lives.
