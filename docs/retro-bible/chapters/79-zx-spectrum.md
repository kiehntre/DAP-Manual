# ZX Spectrum

The ZX Spectrum is tiny, colourful, noisy and historically enormous.

This chapter is the skeleton for preserving Spectrum games with tape images, keyboard notes and an appreciation for the machine's very particular character.

## History

The Spectrum became a defining home computer in the UK and beyond. It supported bedroom coding, budget games, magazine culture and a distinctive visual language.

## Hardware Overview

- Z80-based home computer.
- Tape loading.
- Keyboard-driven interaction.
- Multiple models across the line.

## Why It Mattered

The Spectrum helped create a generation of players and developers. Its influence is cultural as much as technical.

## Preservation Status

Strong, but collections can be messy because of tape variants, cracks, trainers, snapshots and model differences.

## Recommended Emulator

Fuse is a key emulator to document, alongside other maintained options.

## BIOS Requirements

System ROMs may be required depending on emulator and model.

## Recommended File Formats

- `.tzx` and `.tap` for tape preservation.
- Snapshot formats for convenience, clearly labelled.

## Folder Layout

```text
/mnt/games/roms/zxspectrum/
/mnt/games/bios/zxspectrum/
/mnt/games/computers/zxspectrum-notes/
```

## Enhancements

Use display settings that preserve the Spectrum's look. Do not smooth away the charm.

## Common Problems

- Snapshot treated as archival source.
- Wrong model selected.
- Keyboard controls undocumented.
- Tape loading expectations misunderstood.

> **DAP Warning**
>
> Snapshot files are convenient, but they are not the same preservation object as original tape images.

## DAP Gold Standard Setup

- Tape images kept where possible.
- Snapshots labelled as convenience copies.
- Keyboard maps documented.
- Model choice recorded.
