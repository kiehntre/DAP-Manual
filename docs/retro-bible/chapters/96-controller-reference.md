# Controller Reference

Controller setup is easier when the book has one place for house rules.

This chapter is the skeleton for standard layouts, hotkeys, special controllers and streaming input notes.

## Default Hotkeys

| Action | Draft mapping | Notes |
| --- | --- | --- |
| Exit game | To decide | Must work from the sofa. |
| Save state | To decide | Avoid conflicts. |
| Load state | To decide | Dangerous if accidental. |
| Menu | To decide | Emulator-specific. |

## Controller Types

- Modern Xbox-style controller.
- PlayStation-style controller.
- Nintendo Switch Pro controller.
- Arcade stick.
- Light gun.
- Wheel.
- Keyboard and mouse.

## Practical Advice

- Record player order behaviour.
- Keep per-system exceptions.
- Back up emulator profiles.
- Test through Moonlight as well as locally.

> **DAP Warning**
>
> Load-state hotkeys should not be easy to press by accident. Nothing ruins a quiet evening like loading over progress.

## Troubleshooting

### Controller is detected twice

Check Steam Input, emulator input backend and streaming virtual controllers.
