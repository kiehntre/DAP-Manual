# Recommended Hardware

Retro gaming hardware recommendations should be practical, not shopping-list theatre.

This chapter is the skeleton for host machines, GPUs, storage, controllers, displays and streaming clients.

## Host Machines

- Lightweight systems for 8-bit and 16-bit emulation.
- Mid-range PCs for GameCube, Wii, PS2 and many shaders.
- Strong CPU and GPU systems for PS3, Xbox 360 and heavy enhancement work.

## Storage

- SSD for active libraries and demanding disc systems.
- NAS for bulk storage and backups.
- Separate backup target.

## Controllers

- One standard modern controller.
- System-specific controllers where they genuinely improve play.
- Arcade stick for arcade and fighting games.

## Displays and Clients

- TV with game mode.
- Handheld client for Moonlight.
- Desktop monitor for configuration.

> **DAP Warning**
>
> Do not buy hardware for one emulator promise without checking current compatibility and real user reports.

## Practical Advice

- Match hardware to target systems.
- Leave room for storage growth.
- Prefer maintainable setups over exotic builds.
- Document firmware, drivers and connection paths.
