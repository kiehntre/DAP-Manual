# Sony PSP

The PSP brought disc-based PlayStation energy into a handheld that still feels distinctive.

This chapter is the skeleton for PSP preservation with PPSSPP, ISO and CSO choices, saves and enhancements.

## History

Sony's first handheld used UMD media, multimedia features and a library that often felt like a portable branch of the PS2 era.

## Hardware Overview

- UMD optical media.
- Memory Stick storage.
- Widescreen handheld display.
- Digital PSN releases.

## Why It Mattered

The PSP gave handheld games a cinematic, 3D-heavy identity that differed sharply from Nintendo's handheld line.

## Preservation Status

Strong. PPSSPP is mature and portable, and the library is manageable.

## Recommended Emulator

PPSSPP is the standard recommendation.

## BIOS Requirements

No BIOS is required for normal PPSSPP use.

## Recommended File Formats

- ISO for clean source.
- CSO can save space, but test load behaviour.
- Keep DLC and savedata organised separately.

## Folder Layout

```text
/mnt/games/roms/psp/
/mnt/games/dlc/psp/
/mnt/games/saves/psp/
```

## Enhancements

Upscaling works well for many games. Texture replacement and 60 FPS patches exist for selected titles.

## Common Problems

- CSO compression too aggressive.
- DLC folder mismatch.
- Right analogue stick hacks undocumented.
- Save path confusion between standalone and RetroArch.

> **DAP Tip**
>
> PSP is a good place to use per-game enhancement notes because many titles upscale beautifully, while a few prefer restraint.

## DAP Gold Standard Setup

- PPSSPP standalone tested.
- ISO source retained.
- CSO used only after testing.
- Saves and DLC backed up.

## What Comes Next

Next comes PS Vita, where preservation crosses into account-bound digital content and current-ish handheld history.
