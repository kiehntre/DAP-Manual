# Computer Systems, Keyboards and Media

Old computers are not just consoles with keyboards attached.

This draft chapter will cover home computer emulation, disk media, keyboard layouts and the extra patience needed for systems that expected a desk, not a couch.

## Historical Context

- Cover home computers as flexible platforms.
- Explain tapes, floppy disks, hard disks and boot media.
- Note regional keyboard and video differences.

## Concepts

| Concept | Meaning | Draft note |
| --- | --- | --- |
| Disk image | Copy of floppy or hard disk media. | May be writable. |
| Tape image | Cassette data representation. | Loading behaviour can matter. |
| Keyboard matrix | Original key layout. | Modern keyboard mapping can be awkward. |
| Boot disk | Media needed before software runs. | Common for computer systems. |

## Practical Setup

- Decide whether the goal is quick launch or authentic workflow.
- Keep boot media and software media clearly named.
- Document keyboard mappings.
- Use per-game configs for awkward titles.
- Keep writable disk copies separate from clean originals.

## Real-World DAP Setup

- Document which computer systems are included.
- Record launch method per system.
- Note controller versus keyboard expectations.

> **DAP Tip**
>
> Some computer games are better launched as curated entries with notes than forced into a console-style one-click list.

## Common Mistakes

- Expecting every computer title to launch like a cartridge.
- Overwriting writable disk images.
- Forgetting keyboard overlays or command notes.
- Ignoring regional keyboard differences.

## Troubleshooting

### Game asks for a command

- Check original loading instructions.
- Check boot disk requirements.
- Check emulator quick-start options.

### Keys do not match

- Check keyboard layout.
- Check emulator keymap.
- Check host keyboard language.

## Key Points

- Computer emulation needs more context than console emulation.
- Writable media should be protected.
- Keyboard notes are part of the playable library.
