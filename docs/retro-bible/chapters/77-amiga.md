# Amiga

The Amiga is not just another retro computer. It is a scene, a sound, a graphics style and a preservation project with a lot of moving parts.

This chapter is the skeleton for Amiga games on Linux, including Kickstart ROMs, WHDLoad, disk images and controller expectations.

## History

The Amiga brought advanced multimedia hardware into homes during the 1980s and 1990s. It became central to European game development, demos, music and graphics.

## Hardware Overview

- Multiple models and chipsets.
- Kickstart ROMs.
- Floppy disks and hard-drive installs.
- Joystick, mouse and keyboard input.

## Why It Mattered

The Amiga blurred lines between games, creativity and computing in a way few machines managed.

## Preservation Status

Strong but complex. Disk images, WHDLoad installs, cracks, trainers and model differences all matter.

## Recommended Emulator

FS-UAE or UAE-derived cores are the main recommendations to document.

## BIOS Requirements

Kickstart ROMs are required. Version and model compatibility matter.

## Recommended File Formats

- ADF for floppy images.
- IPF where preservation-grade images are available and supported.
- WHDLoad packs for practical play where legally appropriate.

## Folder Layout

```text
/mnt/games/roms/amiga/
/mnt/games/bios/amiga/
/mnt/games/saves/amiga/
/mnt/games/computers/amiga-notes/
```

## Enhancements

Use display settings that respect PAL timing and original aspect. Mouse and keyboard profiles matter.

## Common Problems

- Wrong Kickstart version.
- Wrong model selected.
- Disk swap confusion.
- Joystick and mouse conflict.
- WHDLoad assumptions not documented.

> **DAP Warning**
>
> Amiga setup without Kickstart and model notes will become guesswork very quickly.

## DAP Gold Standard Setup

- Kickstart ROM checksums recorded.
- FS-UAE profiles by machine class.
- WHDLoad and disk-image workflows separated.
- Input notes per game where needed.
