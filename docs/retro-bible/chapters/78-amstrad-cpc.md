# Amstrad CPC

The Amstrad CPC belongs to a home computer world of tapes, disks, keyboards and regional memories.

This chapter is the skeleton for CPC preservation with enough care for media formats and loading behaviour.

## History

The Amstrad CPC line was especially important in the UK, France and parts of Europe. It offered an all-in-one computer experience and a library full of distinctive conversions and originals.

## Hardware Overview

- Z80-based home computer.
- Tape and disk media.
- Keyboard input.
- Colour monitor bundles in many setups.

## Why It Mattered

The CPC was part of the European computer gaming landscape that shaped many players before consoles dominated.

## Preservation Status

Good, but media type, cracks, trainers and regional releases need clear cataloguing.

## Recommended Emulator

Caprice32, Retro Virtual Machine or other maintained CPC emulators should be compared in later passes.

## BIOS Requirements

System ROMs may be required depending on emulator packaging.

## Recommended File Formats

- `.dsk` for disk images.
- `.cdt` or tape formats where appropriate.

## Enhancements

Respect monitor style and aspect. Loading notes are often more useful than visual filters.

## Common Problems

- Tape and disk versions confused.
- Loading commands missing.
- Keyboard layout awkward.
- Emulator model wrong.

> **DAP Tip**
>
> For Amstrad, include the loading method in notes. The frontend can launch the file, but the game may still expect old computer habits.

## DAP Gold Standard Setup

- Media formats separated.
- Emulator model documented.
- Loading commands noted.
- Saves or writable disks protected.
