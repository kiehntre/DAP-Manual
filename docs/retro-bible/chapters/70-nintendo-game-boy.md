# Nintendo Game Boy

The Game Boy proves that technical modesty and cultural weight are different things.

This chapter is the skeleton for preserving original Game Boy games with attention to palettes, borders, saves and handheld feel.

## History

Nintendo's monochrome handheld won through battery life, durability and a library that made portable play part of everyday life.

## Hardware Overview

- 8-bit handheld.
- Cartridge media.
- Monochrome LCD.
- Link cable multiplayer.

## Why It Mattered

It made handheld gaming truly mainstream and carried games into pockets, school bags and long journeys.

## Preservation Status

Excellent. The main practical choices are emulator, palette and save handling.

## Recommended Emulator

SameBoy, Gambatte or mGBA are good candidates depending on workflow.

## BIOS Requirements

Optional boot ROM support may improve authenticity. Normal play does not always require it.

## Recommended File Formats

- `.gb` ROM images.
- Keep Game Boy Color-only titles separate.

## Folder Layout

```text
/mnt/games/roms/gameboy/
/mnt/games/saves/gameboy/
```

## Enhancements

LCD shaders, Super Game Boy borders and palettes are worth documenting separately.

## Common Problems

- Game Boy and Game Boy Color mixed.
- Save battery behaviour misunderstood.
- Palette too harsh on modern screens.

> **DAP Tip**
>
> Game Boy presentation is a taste choice. Keep one clean profile and one nostalgic profile rather than arguing with yourself every launch.

## DAP Gold Standard Setup

- Verified `.gb` files.
- Save folder backed up.
- Palette and shader preset recorded.
- Optional boot ROM noted.
