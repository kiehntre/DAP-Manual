# Sony PlayStation 2

The PlayStation 2 is both familiar and enormous. Its library is a continent.

This chapter is the skeleton for PS2 preservation with PCSX2, BIOS files, disc formats, memory cards and per-game settings.

## History

The PS2 became one of the most successful consoles ever released. It was a DVD player, a backwards-compatible PlayStation machine and a home for almost every genre.

## Hardware Overview

- DVD and CD media.
- Memory cards.
- Regioned BIOS.
- DualShock 2 controller.

## Why It Mattered

Its scale makes it one of the most important preservation targets in console history.

## Preservation Status

Very strong. PCSX2 is mature, but the size of the library means edge cases remain.

## Recommended Emulator

PCSX2 is the standard recommendation on Linux.

## BIOS Requirements

BIOS is required. Region and version should be recorded. Do not distribute BIOS files.

## Recommended File Formats

- ISO or BIN/CUE for source.
- CHD is increasingly practical where supported.
- Keep multi-disc games organised.

## Folder Layout

```text
/mnt/games/roms/ps2/
/mnt/games/bios/ps2/
/mnt/games/saves/ps2/
/mnt/games/texture-packs/ps2/
```

## Enhancements

Internal resolution, widescreen patches, texture packs and deinterlacing choices are the main levers. Test each game before making global claims.

## Common Problems

- Wrong BIOS region.
- Memory card path confusion.
- Aggressive upscaling causing effects glitches.
- Pressure-sensitive button expectations.

> **DAP Warning**
>
> PS2 enhancements are tempting. Start with a known-good native setup, then improve one setting at a time.

## DAP Gold Standard Setup

- PCSX2 installed from documented source.
- BIOS checksums recorded.
- Source and working formats separated.
- Per-game fixes noted.
