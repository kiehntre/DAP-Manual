# BIOS Reference

The BIOS reference is the place readers will visit when an emulator says something is missing and refuses to explain itself kindly.

This chapter is the skeleton for a checked BIOS and firmware table. It must be expanded carefully and must not include copyrighted files.

## Reference Table Skeleton

| System | BIOS required | Notes |
| --- | --- | --- |
| PlayStation | Yes | Region files commonly used. |
| PlayStation 2 | Yes | Dump from owned console. |
| Saturn | Yes | Region matters. |
| Dreamcast | Yes | BIOS and flash commonly used. |
| Game Boy Advance | Optional/recommended | Improves boot accuracy. |
| Nintendo DS | Sometimes | BIOS and firmware for full behaviour. |

## Practical Advice

- Record expected filenames.
- Record checksums.
- Record emulator source.
- Keep BIOS files out of public repositories.
- Back up the BIOS folder.

> **DAP Warning**
>
> This appendix must never include BIOS downloads, firmware files, keys or private account material.

## Troubleshooting

### Emulator rejects BIOS

Check checksum, filename, case sensitivity, region and whether the emulator expects the file in a different folder.
