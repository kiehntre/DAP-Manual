# MS-DOS Gaming

MS-DOS preservation is not just about keeping an executable. It is about keeping a small world around it.

This chapter is the skeleton for DOSBox-style setups, sound cards, installers, CD games and configuration files.

## History

DOS gaming covers shareware, boxed PC games, early CD-ROM experiments, sound-card battles and a wild range of hardware expectations.

## Hardware Overview

- PC-compatible systems across many eras.
- Sound Blaster, AdLib, Gravis and MIDI options.
- Floppy, hard-drive and CD-ROM installs.
- Keyboard, mouse, joystick and gamepad input.

## Why It Mattered

DOS was where PC gaming learned many of its habits: configuration, modding, patches and hardware fiddling included.

## Preservation Status

Good when installers, patches, manuals and configuration are preserved together. Weak when only loose executables survive.

## Recommended Emulator

DOSBox Staging is a strong modern recommendation. DOSBox-X is valuable for broader machine emulation.

## BIOS Requirements

No normal BIOS required for DOSBox-style play.

## Recommended File Formats

- Installed folders with original media retained.
- ISO or BIN/CUE for CD games.
- Keep patches and manuals alongside notes.

## Folder Layout

```text
/mnt/games/pc/msdos/
/mnt/games/pc/msdos-media/
/mnt/games/pc/msdos-notes/
```

## Enhancements

MIDI sound, scaler choices and CRT-style shaders can change the feel dramatically. Record the intended setup.

## Common Problems

- Missing installer media.
- Wrong sound card selected.
- Cycles too high or low.
- CD path not mounted.
- Controls not documented.

> **DAP Tip**
>
> A DOS game entry should include its sound setup. "Works" is not enough if the music is coming from the wrong device.

## DAP Gold Standard Setup

- Original media retained.
- Installed working copy.
- DOSBox config per game or series.
- Manuals and patches stored.
