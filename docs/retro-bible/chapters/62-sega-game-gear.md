# Sega Game Gear

The Game Gear is the Master System's portable cousin, but its screen and library give it a personality of its own.

This chapter is the skeleton for organising Game Gear games with handheld display expectations and Sega 8-bit context.

## History

Sega's colour handheld competed directly with the Game Boy. It was technically flashier, battery-hungry and home to a library that mixed ports, exclusives and regional curiosities.

## Hardware Overview

- 8-bit handheld.
- Colour LCD screen.
- Cartridge media.
- Closely related to Master System hardware.

## Why It Mattered

It shows Sega's handheld ambitions and gives many 8-bit Sega games a different context.

## Preservation Status

Strong. The main concerns are region variants, hacks and display presentation.

## Recommended Emulator

Genesis Plus GX, ares or other mature Sega 8-bit emulators.

## BIOS Requirements

BIOS is not normally required for basic play, though some emulator modes may support it.

## Recommended File Formats

- `.gg` ROM images.
- Keep Master System conversions and hacks clearly labelled.

## Folder Layout

```text
/mnt/games/roms/gamegear/
/mnt/games/saves/gamegear/
```

## Enhancements

Use LCD-style shaders or clean scaling rather than a living-room CRT look by default.

## Common Problems

- Master System and Game Gear ROMs mixed together.
- Display shader too harsh.
- Regional names scraped incorrectly.

> **DAP Tip**
>
> Handheld systems deserve handheld presentation. A subtle LCD shader can feel more honest than a heavy CRT mask.

## DAP Gold Standard Setup

- Verified ROMs.
- Game Gear kept separate from Master System.
- LCD presentation preset documented.
- Saves backed up.

## What Comes Next

Next comes PlayStation, where optical media, BIOS files and memory cards become central.
