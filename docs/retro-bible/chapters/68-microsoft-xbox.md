# Microsoft Xbox

The original Xbox is where console preservation starts to feel unusually close to PC preservation.

This chapter is the skeleton for Xbox emulation, disc formats, dashboard history and the hardware identity that made the machine different.

## History

Microsoft entered the console market with a powerful machine, hard drive, Ethernet and a controller that slowly became a PC standard in spirit.

## Hardware Overview

- DVD-based console.
- Internal hard drive.
- Dashboard and system files.
- Xbox Live services.
- Controller layout that influenced modern pads.

## Why It Mattered

The Xbox pushed online console infrastructure and hard-drive-based console design forward.

## Preservation Status

Improving, but more uneven than PlayStation 2 or GameCube. Dashboard and system-file questions need care.

## BIOS Requirements

Xbox emulation normally requires original system files and hard-drive images from owned hardware. Do not distribute them.

## Recommended File Formats

- XISO or emulator-supported disc images.
- Keep extracted and converted copies documented.

## Folder Layout

```text
/mnt/games/roms/xbox/
/mnt/games/bios/xbox/
/mnt/games/saves/xbox/
```

## Enhancements

Upscaling and widescreen patches may work for selected titles. Compatibility should be checked per game.

## Common Problems

- Missing MCPX or BIOS material.
- Wrong disc format.
- Dashboard image confusion.
- Controller mapping quirks.
